# Contributing

Bug reports and ideas are welcome as issues. This is a personal project kept up in spare time, so open an issue before writing a large change. Small fixes can come as pull requests.

How to build and test is in [docs/BUILD.md](docs/BUILD.md) and [docs/TESTING.md](docs/TESTING.md). A workflow runs the server's tests on every pull request.

This repository is a published copy of a working repository, and each update arrives as one commit. An accepted pull request is applied there and shows up in the next update, rather than being merged with the merge button.
