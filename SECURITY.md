# Security

## Reporting a problem

Use GitHub's private vulnerability reporting: open the Security tab of this repository and choose "Report a vulnerability", or go to <https://github.com/wandering-wampa/unison-reader/security/advisories/new>. Please do not open a public issue for a security problem.

This is a one-person project, so a reply can take some days.

## Versions

Only the latest release gets fixes.

## What is in scope

The server, the web client and the Android and Wear OS apps: for example a way to read another person's shelf or places, to sign in without a password, to write to the library folders, or to reach files outside the data folder.

The README's Status section lists known limits that are not findings: sign-in is a password with no second factor, and the APKs are debug-signed builds.
